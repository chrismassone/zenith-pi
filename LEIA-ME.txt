ZENITH - Projeto Integrador (FATEC)
Sistema desktop da clinica da Dra. Gabriela Saraiva. Python + MySQL 8.
Todos os dados de exemplo sao FICTICIOS.

INSTALAR (primeira vez)
1. Instale o Python 3.14 e o MySQL 8.
2. De dois cliques em instalar.bat (instala o requirements.txt).
3. Copie ".env.example" para ".env" e coloque a senha do usuario zenith_app.
   O .env NUNCA vai para o Git e nunca deve ser enviado a ninguem.

MONTAR O BANCO DO ZERO (como root, no MySQL Workbench)
1. Backup do banco atual (Prompt de Comando, dentro da pasta bin do MySQL):
   mysqldump -u root -p --routines --triggers --databases zenith > "%USERPROFILE%\Documents\zenith_backup.sql"
2. Execute banco\zenith_completo.sql (ATENCAO: apaga e recria o banco zenith,
   com estrutura, dados ficticios e consultas).
3. Abra banco\zenith_permissoes.sql, troque TROQUE_ESTA_SENHA pelas senhas de
   cada usuario (a do zenith_app e a do .env) e execute. Nao salve o arquivo
   com as senhas.
4. Para os testes automaticos: execute banco\teste\zenith_banco_teste.sql
   (cria o banco separado zenith_teste) e depois rode:  python banco_teste.py carregar

   Os arquivos de banco\historico (zenith_banco.sql, zenith_populacao.sql e
   zenith_consultas.sql) sao as fontes do script completo. Depois de alterar
   algum deles, gere de novo:  python gerar_sql_completo.py

CRIAR O PRIMEIRO USUARIO
   python criar_usuario.py
   (pede nome, e-mail, perfil e a senha sem mostrar na tela; minimo 10 caracteres)
   Perfis: Gerente (tudo), Atendente (sem Financeiro/Dashboard; Unidades so
   leitura; sem anamnese), Profissional (Pacientes, Atendimentos, anamnese).

USAR
   De dois cliques em iniciar.bat (ou: python main.py) e entre com e-mail e senha.
   5 senhas erradas seguidas bloqueiam o acesso por 15 minutos.
   30 minutos sem uso encerram a sessao.

TESTAR
   testar.bat roda todos os testes. Os que gravam usam SOMENTE o banco
   zenith_teste e apagam o que criaram. Os de interface abrem a janela.

CONSULTAS E POWER BI
   banco\historico\zenith_consultas.sql - consultas comentadas (python consultas_executar.py)
   docs/powerbi_views.md - views e visuais do Power BI
   docs/modelo_dados.md  - DER, cardinalidades, dicionario e perguntas a cliente

FONTE
   A fonte Montserrat esta em assets\fontes. Sem ela o programa usa a Segoe UI
   (baixe em https://fonts.google.com/specimen/Montserrat).
